# Compilador Micro-Pascal (Parte 1: Léxico e Sintático)

Projeto desenvolvido para a disciplina de Construção de Compiladores.

## Estrutura do Projeto

- `include/`: Arquivos de cabeçalho (`.h`)
- `src/`: Implementações em C (`.c`)
- `tests/`: Programas Micro-Pascal de teste (`.pas`)

## Como Compilar

No terminal do Linux/PowerShell com `make` configurado:

```bash
make
